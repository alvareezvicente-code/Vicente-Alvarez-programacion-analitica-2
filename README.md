# Proyecto final - Programación Analítica II

## Arroyo Capital: inversión y portafolio en la industria del cine

Proyecto final de Vicente Alvarez para la materia Programación Analítica II de la Licenciatura en Ciencia de Datos para Negocios de la Universidad de Montevideo.

El objetivo es analizar información histórica de la industria cinematográfica y desarrollar una tesis de inversión para distribuir USD 500 millones entre distintos tipos de películas.
